## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/OracleForge.git`
2. `cd OracleForge`
3. Install in editable mode: `pip install -e .`

## Configuration

OracleForge is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
